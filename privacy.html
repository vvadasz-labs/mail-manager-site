Privacy policy

mail-manager is a personal tool used only by its owner, Valentin Vadász, on his own Gmail account. It has no other users.

What it accesses

With the gmail.modify permission it reads messages and their labels, adds and removes labels, and removes the Inbox label to archive messages. It never sends, deletes or trashes email.

How data is processed

To classify a message, a bounded, cleaned excerpt (sender, subject, selected headers and the beginning and end of the body) is sent to the OpenAI API and processed under OpenAI's API data-usage terms. Message excerpts and classification results are stored in a local database on the owner's own server. No data is sold, shared for advertising, or disclosed to anyone else.

Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
